# ZII POS — Shared Types Package (`@zii/types`)

Package tipe data TypeScript terpusat yang dibagikan ke seluruh aplikasi di monorepo (`apps/web` dan `apps/api`).

---

## 📌 Exported Interfaces

- `Tenant` — Model data merchant & white-label config.
- `User` — Model pengguna (kasir / owner).
- `Product` — Model barang dan jasa.
- `Transaction` — Header data transaksi penjualan.
- `TransactionItem` — Detail item belanja.
- `CreateTransactionInput` — DTO untuk membuat transaksi baru.
